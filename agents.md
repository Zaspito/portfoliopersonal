\# Instrucciones del proyecto



El proyecto es una web portfolio profesional de Ángel Muñiz Pedraza.



Prioridades

\- Diseño premium, tecnológico y visualmente impresionante.

\- Código limpio, modular y mantenible.

\- React + TypeScript + Vite + Tailwind.

\- Usar animaciones con Framer Motion.

\- Usar Three.js o React Three Fiber para elementos 3D.

\- Mantener buen rendimiento y responsive design.

\- No crear una plantilla genérica.

\- Separar la web en componentes reutilizables.

\- Ejecutar build y corregir errores antes de finalizar.



Tono visual

Futurista, profesional, oscuro, elegante, con detalles neón y glassmorphism.



No inventar datos personales fuera de los proporcionados.
